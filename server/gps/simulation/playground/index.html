OSRM API Playground

Each tab below hits its own PHP endpoint (route.php, nearest.php, table.php, match.php, trip.php), which forwards the request to router.project-osrm.org and returns the raw JSON. Responses stack up in the log so you can compare services one by one.

Route /route/v1/{profile}/{coordinates}

Fastest path between two or more points, with full geometry, turn-by-turn steps and annotations.

Nearest /nearest/v1/{profile}/{coordinate}

Snaps a single point onto the closest matching road segments.

Table /table/v1/{profile}/{coordinates}

Duration/distance matrix between every pair of points — useful for comparing many stops at once.

Match /match/v1/{profile}/{coordinates}

Snaps a noisy GPS trace (e.g. from a moving vehicle) onto the road network.

Trip /trip/v1/{profile}/{coordinates}

Solves a travelling-salesman route that visits every given point.

Geocode nominatim.openstreetmap.org/search?q={query}

Looks up a place name and returns its coordinates (not an OSRM service — used to populate gps_locations).
